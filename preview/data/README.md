# データ仕様（メタル脳 — オパビのイヤホン帳）

サイトに表示するデータは、このフォルダの2ファイルが**正本**です。
別のチャットやメモで書いた内容は、この形式に直してから反映します。
Google ドライブの `iem-collection.html` は古い試聴メモです。ランク・役割などは**このフォルダのデータを正**とします。

| ファイル | 中身 |
|---|---|
| `models.js` | 所持IEM（`MODELS`）・表示順（`ORDER`）・写真の情報（`PHOTOS`） |
| `wishlist.js` | 欲しいものリスト（`WISHLIST`） |

---

## 1. 所持IEM（`MODELS`）

### 必須項目

| 項目 | 型 | 説明 |
|---|---|---|
| `id` | 文字列 | 英小文字・数字・ハイフンのみ。URL（`#lucifer`）と写真のファイル名に使う。**あとから変えない** |
| `brand` | 文字列 | メーカー名。表記は下の「メーカー表記」に合わせる |
| `name` | 文字列 | 機種名。頭文字が一覧で役割の色になる |
| `rank` | 文字列 | `S` / `A` / `BP`（＝B+） / `B` / `C` / `D` / `X`（＝評価外） |
| `axis` | 配列 | 役割。**最大2つ、主 → 副の順**。`power`（圧）/ `atmosphere`（響）/ `edge`（切）。未設定は `[]` |
| `drivers` | 文字列 | ドライバ構成の短い表記（例 `2DD+3BA`） |

### レビュー本文（詳細画面に出る項目）

| 項目 | 型 | 表示場所 | 書き方のめやす |
|---|---|---|---|
| `catch` | 文字列 | 一覧・詳細の見出し | 1行。20字前後 |
| `lead` | 文字列 | 詳細の導入文。**S ランクは一覧にも表示** | 1〜2文 |
| `spec` | 文字列 | 詳細のスペック行 | 例 `1DD / 10mm チタン振動板 / 64Ω` |
| `genre` | 文字列 | 一覧・詳細 | 担当ジャンルを「・」区切り |
| `tone` | オブジェクト | 詳細「音の印象」 | 楽器ごとの**短いキーワード**（各2〜3語・1語10字前後）。`{ low:['…','…'], mid:['…'], stage:['…'] }`。`low`＝リズム隊（ドラム・ベース）、`mid`＝上モノ（ギター・ヴォーカル・シンセ）、`stage`＝空間（定位・広さ・残響）。各キーワードは**「形容＋楽器名」**で書く（例：スピード感のあるキック／エモいヴォーカル）。リズム隊はキック・スネア・金物・ベース、上モノはギター・ヴォーカル・シンセ・楽器隊などを名指しする。空間は「定位は正確」「横に広い」のように項目＋状態で書く。ひと目で性格をつかむための要約で、理由や場面は「好きなところ／気になるところ」に文章で書く。文字列で書くと文章として表示される（下書き用） |
| `good` | 配列 | 詳細「LIKE ／ 好きなところ」 | 1項目1文。3〜4項目 |
| `bad` | 配列 | 詳細「HMM ／ 気になるところ」 | 1項目1文。2〜3項目 |
| `fit` | 文字列（任意） | 詳細「装着感」 | 装着感に特記事項があるときだけ |
| `verdict` | 文字列 | 詳細「VERDICT ／ ひとことで言うと」 | 強調したい語を `**語**` で囲む（1か所まで）。例 `例えるなら**山のフドウ**。` |
| `songs` | 配列 | 詳細「PLAYLIST」 | 下の「おすすめ曲」を参照 |
| `related` | 配列 | 詳細「VS ／ 比べるなら」 | `[ ['相手のid', '比較の一文'], … ]`。相手の詳細が公開済みならリンクになる 。**同じメーカーどうし（ZiiGaat、ARTPICAL など）や近い価格帯どうしは、お互いに書いておく**と、詳細から詳細へ読み進めてもらいやすい |
| `setup` | 文字列 | 詳細「SETUP ／ 試聴環境」 | 例 `TRKAPLST Ink / M5 Ultra（vol70で十分）` |
| `log` | 配列（任意） | 詳細「検証ログ」（折りたたみ） | `[ ['見出し', '本文'], … ]`。不要なら `[]` |
| `tempo` | オブジェクト（任意） | 詳細「TEMPO ／ 合う曲の速さ」 | 1＝遅い〜5＝速い の5段階。`{ range:[3,5], best:4 }`（合う範囲と、いちばん合う段階）。得意な速さが2つあるときは `best:[2,4]` のように配列で書く（凡例は「特に合う」になる）。`note:'…'` で一言添えられる。書かなければ表示しない |

#### 合う曲の速さ（`tempo`）の目安
BPM はあくまで目安。最後は体感で決める（ブレイクダウンのハーフタイムは体感で数える、など）。

| 段階 | 表示 | BPM の目安 | 曲のイメージ |
|---|---|---|---|
| 1 | 遅い | 〜90 | ドゥーム、スラッジ、ドローン |
| 2 | やや遅い | 90〜130 | ブレイクダウン、グルーヴメタル、ポストメタル |
| 3 | 中くらい | 130〜180 | 正統派、メタルコアの歌のパート |
| 4 | やや速い | 180〜230 | スラッシュの疾走、メロデスのツーバス |
| 5 | 速い | 230〜 | ブラストビート、グラインド、250超えのスラッシュ |

#### おすすめ曲（`songs`）
```js
songs: [
  ['Thousand Eyes - One Thousand Eyes', 'https://youtu.be/…', true, '1:20〜のギターソロで、エッジと厚みの両立が分かる'],  // 3番目に true で「いちばん推し」、4番目は一言メモ
  ['Nightwish - Ghost Love Score (Live)', 'https://youtu.be/…'],
],
```
- 曲名は **`アーティスト - 曲名`**（半角ハイフンの前後に半角スペース）で書く。表示で曲名とアーティストに分ける。
- 「いちばん推し」は1曲だけ。
- **検証に使うリファレンス曲（このカタログの読み方に載せている6曲）は、おすすめ曲には入れない**。リファレンス曲での比較は「検証ログ」に書く。
- 4番目に一言メモを書ける（任意）。**この曲のどこで、この機種の良さが分かるか**を1行で。曲名の下に小さく表示される。基本は「いちばん推し」にだけ書く。推しでない曲に書くときは、3番目を `false` にする（例：`['…', 'https://…', false, '…']`）。

### ランクごとの書く量
| ランク | 書く内容 | 一覧での見え方 |
|---|---|---|
| S・A・B+ | フルの詳細（上の項目すべて） | 写真付きで、タップすると詳細が開く |
| B | **簡易版**：`catch`・`genre`・`axis`・`tone`（キーワード）・`verdict`。`lead` や `good`／`bad` は任意。おすすめ曲・テンポ・比較・試聴環境は書かない | 台帳の行。書き終えた機種だけ右端に「→」が付き、詳細が開く |
| C・D・評価外 | `catch`（一言の理由）だけ。詳細は作らない | 名前と一言だけの一覧。`pending` は付けない |

- 詳細の各欄は、書いた項目だけが表示される（空の欄は出ない）。
- B を書き終えたら `pending:true` を消す。

### 状態・写真の調整

| 項目 | 型 | 説明 |
|---|---|---|
| `pending` | 真偽値 | `true` ＝レビュー準備中（S〜B のみ）。一覧では灰色＋「準備中」札（B は台帳の行のまま）で、タップできない。**詳細を書き終えたら項目ごと消す** |
| `ev` | 文字列 | 内部管理用（`listened`＝実聴／`review`＝レビュー参考）。画面には出ない |
| `photoPos` | 文字列（任意） | 写真の切り抜きの中心。例 `'62% 45%'`（横・縦）。省略時は中央 |
| `photoZoom` | 数値（任意） | 一覧のカードでの拡大率。例 `1.4`。被写体が小さく写っている写真用 |

### 表示順（`ORDER`）
- 一覧はランクごとに分けたうえで、`ORDER` に並べた `id` の順で表示する。
- 新しい機種を足したら、`ORDER` の入れたい位置にも `id` を追加する。

## 2. 写真

| ファイル | 用途 |
|---|---|
| `img/<id>-card-800.webp` | 一覧（幅800px） |
| `img/<id>-full-1600.webp` | 詳細・拡大表示（幅1600px。元写真が小さい場合は800） |

- `PHOTOS` に、元写真の幅・高さ・明るさ（`lum`、0〜1）を登録する。暗い写真（`lum` が0.3未満）は、一覧のカードでだけ自動で明るく補正される（黒は黒のまま、中間の明るさを持ち上げる）。詳細と拡大表示は元の写真のまま。
- 写真がない機種は、ドライバ構成の文字だけの枠で表示される。
- **撮影のめやす**：明るめの背景（グレーや白の布、木の机など）で撮ると、役割の色の板とよくなじむ。

## 3. 欲しいものリスト（`WISHLIST`）

```js
{ brand: 'Yanyin', name: 'Baker', drivers: '6BA+2Planar', note: '平面の鳴り方が気になる' },
{ brand: '7Hz', name: 'Diablo（× Crinacle）', drivers: '1Planar' },
```
- コラボ機は **`機種名（× 相手）`** と、機種名の後ろにカッコで書く。
- 項目は **機種名・メーカー・ドライバ構成**。価格や優先度は載せない。
- 任意で `note:'…'`（気になっている理由などの一言）を足せる。書いた機種だけ、名前の下に小さく表示される。
- 表示はメーカーごとにまとめ、メーカー名のアルファベット順に並べる。書く順番は自由。
- 構成が不明なものは `'非公開'` のように文字で書く。
- 購入したら、`WISHLIST` から消して `MODELS` に追加する。

## 4. 表記のルール

### メーカー表記
所持・欲しいもので**同じ書き方にそろえる**（絞り込みや集計で別メーカー扱いになるのを防ぐため）。

| 正 | 誤 |
|---|---|
| `ZiiGaat` | `Ziigaat` |
| `ARTPICAL` | `Artpical` |
| `NICEHCK` | `NiceHCK` |

新しいメーカーが出てきたら、この表に追記する。

### 役割（`axis`）
| 値 | 表示 | 色 |
|---|---|---|
| `power` | 圧（圧・量感） | マゼンタ |
| `atmosphere` | 響（残響・空間） | すみれ色 |
| `edge` | 切（速さ・輪郭） | シアン |

- 最大2つ。1つ目が主（板と頭文字の色）、2つ目が副（2枚目の板の色）。3つ以上書いても3つ目以降は表示されない。

### 呼び名（比較文 `related` 用）
機種ごとに決まった呼び名を持たせ、比較文は基本的に **`呼び名A機種A、呼び名B機種B`** の形で作る。
- 同じ比較文を**両方の機種に書く**（相互リンク）。
- 呼び名どうしで違いが出ないペア（兄弟機や、同じ役割で比べたい点が別にあるもの）だけ、そのペア専用の言い方にしてよい。
- 新しい機種を足したら、ここに呼び名を追記する。**他の機種と言葉が重ならない**ようにする。

| 機種 | 呼び名 | 比較文での書き方 |
|---|---|---|
| Cano Cristales | 暴力的なアタックの | 暴力的なアタックのCano |
| Lucifer | 熱さと厚さの | 熱さと厚さのLucifer |
| Martilo | 重さと汎用の | 重さと汎用のMartilo |
| Doscinco | 厚く包み込む | 厚く包み込むDoscinco |
| Arcadia | 狭く重苦しい | 狭く重苦しいArcadia |
| Cincotres | 冷たく精密な | 冷たく精密なCincotres |
| Luna | 温かみと残響の | 温かみと残響のLuna |
| Gabriel | 元気で立体的な | 元気で立体的なGabriel |
| Estrella | 華やかさと見通しの | 華やかさと見通しのEstrella |
| Odyssey | 分離と音場の | 分離と音場のOdyssey |
| Himalaya | 広さとキレの | 広さとキレのHimalaya |
| Canon | 勢いと荒削りの | 勢いと荒削りのCanon |

ペア専用の言い方：
- Doscinco ⇔ Cincotres（兄弟機）：`包み込む力のDoscinco、切り分ける技のCincotres`
- Cano ⇔ Martilo：`アタックのCano` と `重さのMartilo` の対比

### 同じジャンルを複数の機種に書くとき（`genre`）
好きな音を集めているので、ジャンルが重なるのは自然なこと。ジャンル欄は「その機種で特に気持ちよく聴けるもの」を書く。聴かせ方の違いを言葉にできたものだけ、参考として下の表に残す。

| ジャンル | 機種 | 聴かせ方 |
|---|---|---|
| インダストリアル | Cano Cristales | 機械的な圧力 |
| | Cincotres | 血の通ってない冷徹さ |
| | Gabriel | 空間に広がる華やかさ |

## 5. 記入例（1機種ぶん）

```js
{
  id:'lucifer', brand:'ARTPICAL', name:'Lucifer', rank:'S', axis:['power','edge'], ev:'listened',
  photoPos:'55% 55%',
  drivers:'1DD', spec:'1DD / 10mm チタン振動板 / 64Ω',
  catch:'激情増幅装置',
  lead:'エッジーでマッシブでエモーショナルな情熱の悪魔。',
  genre:'デスラッシュ・メタルコア',
  good:['まず耳を引くのはギター。エッジが立って分厚い', '…'],
  bad:['何でも派手で刺激的に鳴らすから、ドゥームは苦手疑惑', '…'],
  verdict:'リフ主体の爆走曲は**こいつで決まり**！',
  tempo:{ range:[3,5], best:4 },
  tone:{ low:['横から挟む圧','サブベース控えめ'], mid:['分厚くエッジが立つ','声がエモい'], stage:['横に広い','縦はやや潰れ気味'] },
  songs:[
    ['Thousand Eyes - One Thousand Eyes','https://youtu.be/A7rWTwgdW2s', true],
  ],
  setup:'TRKAPLST Ink / M5 Ultra（vol70で十分）',
  related:[ ['cano-cristales','ギターの厚みならLucifer、ローの重さならCano'] ],
  log:[],
},
```

レビュー中の機種（詳細なし）は、最低限これだけでよい。

```js
{ id:'estrella', pending:true, brand:'ZiiGaat', name:'Estrella', rank:'BP', axis:[], drivers:'2DD+4BA', catch:'派手なV字', genre:'' },
```
